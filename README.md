# 잡아라! 코지 룸 🛋️

물리 기반 캐주얼 파티 게임 — 흐느적 캐릭터로 한 방에 모여, 엉뚱한 주제에 맞는
물건을 뺏고 던지며 쟁탈전을 벌이고, **AI 심사위원**의 유쾌한 한 줄 평과 함께
우승자를 가립니다.

> NAN 게임 AI 해커톤 출품작. 설계 문서는 [DESIGN.md](DESIGN.md) 참고.

## 플레이 방법

| | 이동 | 잡기 / 던지기 | 점프 |
|---|---|---|---|
| P1 | `W` `A` `S` `D` | `Space` | `L-Shift` |
| P2 | 방향키 | `Enter` | `R-Shift` |
| P3·P4 | 게임패드 스틱 | `A` | `B` |

키보드 배치는 메뉴에서 `K`를 눌러 변경할 수 있습니다 (브라우저에 저장).
혼자라면 메뉴에서 `B`를 눌러 **AI 봇**을 추가하세요 (로컬 행동 로직 — API 비용 없음).

1. 메뉴에서 자기 **잡기 버튼**을 누르면 참가 (1~4인), `R` 키로 시작.
2. 화면 중앙에 **주제**가 뜹니다. 예: "좀비가 몰려온다! 지금 당장 무기로 쓸 것은?"
3. 25초 동안 방 안의 물건을 **잡고, 뺏고, 던지세요.**
   - 던진 물건에 맞으면 들고 있던 물건을 떨어뜨립니다.
   - 같은 물건을 동시에 잡으면 **물리 줄다리기** — 지는 쪽은 **팔이 뜯어져**
     아이템으로 바닥에 뒹굽니다. 남이 주워 튈 수도 있고, 되찾아 잡으면 재장착!
4. 2라운드부터는 **랜덤 이벤트**가 방을 뒤흔듭니다 — 바닥 왁스칠(과속 빙판) /
   돌풍(방향풍이 물건을 쓸어감) / 달 중력 / 미스터리 룸(실루엣) /
   **사물들이 이상해졌다**(전부 회색 도형이 되어 잡아봐야 정체를 앎).
   난투 중 **보급 비행선**이 지나가며 장비를 떨어뜨립니다:
   돌풍폭탄(주변 밀치기·자해) / 스카우터(모든 물건 이름 표시) / 레이저 안경(정면 빔).
   똑같이 생겼지만 정체가 다른 **트윈 물건**(수박↔수박 비치볼, 야구방망이↔방망이 연필)도 섞여 있습니다.
5. 매치 중 한 라운드는 **일치 라운드**: "모두 【곰인형】 들어라!" — 그런데
   복제본이 **인원수보다 하나 모자랍니다** (의자앉기). 닮은꼴 미끼까지 섞여
   있어서, 버저 후 틀린 사람은 **카메라 클로즈업 + 스포트라이트 + 드럼롤**과
   함께 오늘의 주인공이 됩니다. "이런… 프라이팬같이 생긴 탁구채였습니다!"
6. 버저가 울리는 순간 **손에 든 물건**이 제출물. AI 심사위원이 채점 + 한 줄 평.
7. 3라운드 누적 점수로 우승자 결정.

매치마다 방 테마(코지 거실 / 야근 사무실 / 심야 주방)가 랜덤으로 선택되어
팔레트·가구 배치·프롭 구성이 달라집니다. 효과음과 배경음악은 전부 WebAudio로
실시간 합성됩니다 (외부 오디오 에셋 없음).

## 온라인 멀티플레이 + 보이스챗

호스트 권위 방식의 온라인 모드가 내장되어 있습니다. 릴레이 서버 하나만 띄우면 됩니다:

```bash
cd server && npm install && npm start   # ws://localhost:8787
```

1. **호스트**: 게임 메뉴에서 `O` → 4자리 방 코드와 참가 주소가 표시됩니다.
2. **게스트**: `주소?join=코드&relay=ws://…` 로 접속 — 물리는 호스트에서 돌고
   게스트는 입력만 보냅니다 (스냅샷 20Hz 미러링).
3. **보이스챗**: 누구든 `V` 를 누르면 마이크가 켜지고 방 전원과 P2P(WebRTC)로
   연결됩니다. 다시 누르면 음소거. 서버를 거치지 않아 릴레이 부하가 없습니다.

배포 시 릴레이 주소는 `?relay=wss://…` 파라미터 또는 빌드 환경변수
`VITE_RELAY_URL` 로 지정합니다. 무료 배포 후보와 설계는
[docs/5-온라인모드-설계.md](docs/5-온라인모드-설계.md) 참고.
결과 화면에서 `R` 을 누르면 온라인 방을 유지한 채 같은 멤버로 재경기합니다.

## AI 연동 (LLM 심사 · 생성형 3D)

- **LLM 심사위원**: 릴레이 서버에 `NVIDIA_API_KEY` 가 설정돼 있으면(`server/.env`,
  gitignore됨) 매 라운드 심사가 NVIDIA NIM(라마 8B)으로 실행됩니다.
  라운드당 1회 호출·토큰 캡으로 비용을 최소화하며, 실패 시 로컬 심사로 자동 폴백.
- **Meshy 캐릭터 파이프라인**: `.mcp.json` 에 Meshy MCP 서버가 등록되어 있고
  (`MESHY_API_KEY` 환경변수 필요), `tools/meshy-characters.mjs` 로 젤리빈 4색
  캐릭터 GLB를 생성할 수 있습니다. 원격 개발 환경에서 실행하려면 네트워크
  허용 목록에 `api.meshy.ai`, `assets.meshy.ai`, `integrate.api.nvidia.com`,
  `*.cloudfront.net` 추가가 필요합니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입체크 + 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 로컬 확인
```

개발·시연용 단축 모드: URL에 `?fast`를 붙이면 난투가 6초로 줄어듭니다.

기술 스택: **Vite + TypeScript + Three.js(렌더링) + Rapier3d(물리, WASM)** — 서버 없는 정적 빌드.

### AI 심사위원 교체

기본은 오프라인 로컬 심사기입니다. 실제 LLM 심사 프록시가 있다면 URL 파라미터로 연결:

```
https://.../?judge=https://my-judge-endpoint.example/judge
```

요청/응답 형식은 [`src/judge.ts`](src/judge.ts)의 `RemoteJudge` 참고. 실패 시 로컬 심사로 자동 폴백.
