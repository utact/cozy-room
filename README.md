# 잡아라! 코지 룸 🛋️

물리 기반 캐주얼 파티 게임 — 흐느적 캐릭터로 한 방에 모여, 엉뚱한 주제에 맞는
물건을 뺏고 던지며 쟁탈전을 벌이고, **AI 심사위원**의 유쾌한 한 줄 평과 함께
우승자를 가립니다.

> NAN 게임 AI 해커톤 출품작. 설계 문서는 [DESIGN.md](DESIGN.md) 참고.

## 플레이 방법

| | 이동 | 잡기 / 던지기 |
|---|---|---|
| P1 | `W` `A` `S` `D` | `Space` |
| P2 | 방향키 | `Enter` |
| P3·P4 | 게임패드 스틱 | 게임패드 `A` |

1. 메뉴에서 자기 **잡기 버튼**을 누르면 참가 (1~4인), `R` 키로 시작.
2. 화면 중앙에 **주제**가 뜹니다. 예: "좀비가 몰려온다! 지금 당장 무기로 쓸 것은?"
3. 25초 동안 방 안의 물건을 **잡고, 뺏고, 던지세요.**
   - 던진 물건에 맞으면 들고 있던 물건을 떨어뜨립니다.
   - 같은 물건을 동시에 잡으면 물리 줄다리기!
4. 2라운드부터는 **랜덤 이벤트**가 방을 뒤흔듭니다 — 🧼 바닥 왁스칠 / 🌪️ 돌풍 / 🌙 달 중력.
5. 버저가 울리는 순간 **손에 든 물건**이 제출물. AI 심사위원이 채점 + 한 줄 평.
6. 3라운드 누적 점수로 우승자 결정.

효과음은 전부 WebAudio로 실시간 합성됩니다 (외부 오디오 에셋 없음).

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입체크 + 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 로컬 확인
```

개발·시연용 단축 모드: URL에 `?fast`를 붙이면 난투가 6초로 줄어듭니다.

기술 스택: **Vite + TypeScript + Three.js(렌더링) + Rapier3d(물리, WASM)** — 서버 없는 정적 빌드.

### AI 심사위원 교체

기본은 오프라인 로컬 심사기입니다. 실제 LLM 심사 프록시가 있다면 URL 파라미터로 연결:

```
https://.../?judge=https://my-judge-endpoint.example/judge
```

요청/응답 형식은 [`src/judge.ts`](src/judge.ts)의 `RemoteJudge` 참고. 실패 시 로컬 심사로 자동 폴백.
