# 게임 소개 및 설명 문서

## 게임 제목

**잡아라! 코지 룸** (Grab It! Cozy Room)

## 한 줄 소개

엉뚱한 주제에 맞는 물건을 잡아라 — 뺏고, 던지고, AI 심사위원의 유쾌한 채점을
받는 물리 난투 파티 게임 (최대 4인, 노트북 한 대에서 함께)

## 게임 방법

### 목표
매 라운드 제시되는 주제(예: "집에 불났다! 하나만 들고 튀어라!")에
가장 어울리는 물건을 **버저가 울리는 순간 손에 들고 있으면** 승리.
3라운드 누적 점수로 최종 우승자를 가린다.

라운드마다 **맵이 바뀐다** — 코지 거실과 오토캠핑 데크. 맵이 바뀌면 주제도 그 맵의
것으로 바뀐다. 캠핑장에서 나오는 "캠핑 왔는데 이건 진짜 아니지 않냐?" 같은 주제는
바닥에 굴러다니는 노트북·무선청소기가 그대로 정답이 되는 식이다.

바닥에는 물건 22개가 널려 있지만 **주제에 딱 맞는 물건은 몇 개 없다.** 좋은 답을
먼저 집거나, 남이 든 걸 뺏어야 한다.

### 조작
노트북 한 대를 둘이 나눠 쓴다. 왼쪽이 1P, 오른쪽이 2P. 빈자리는 AI 봇이 채운다.

| | 이동 | 잡기 / 던지기 |
|---|---|---|
| P1 | `W` `A` `S` `D` | `Space` |
| P2 | 방향키 | `Enter` |

- 한 사람당 키는 이동 4개 + 잡기/던지기 1개가 전부다. **점프는 없다** —
  테이블이나 소파 위에 놓인 물건도 그냥 집을 수 있어서 필요가 없다
- 로비에서 자기 **잡기 키**를 누르면 참가, `R` 키로 시작
- `B` 키로 AI 봇을 넣을 수 있다 (최대 4인)
- 빈손이면 근처 물건 잡기, 들고 있으면 바라보는 방향으로 던지기
- **던진 물건에 맞으면** 들고 있던 물건을 떨어뜨린다 (쟁탈전)
- 같은 물건을 동시에 잡으면 물리 줄다리기 — 더 세게 버둥거린 쪽이 가져간다
- 3라운드 중 한 번은 **일치 라운드** — 지목된 물건 하나를 모두가 동시에 노린다.
  그 물건은 **인원수보다 딱 하나 적게** 놓인다(4인이면 3개). 의자 뺏기 게임과 같아서
  마지막 하나를 놓친 사람이 나온다. 게다가 방에는 위에서 보면 헷갈리는 닮은꼴이
  함께 있어 급하게 집으면 엉뚱한 걸 들고 서 있게 된다
- 2라운드부터 방의 사물이 사고를 친다. **어떤 사고가 나는지는 맵이 정한다**:
  - 코지 거실 — 🌪️ **누가 또 창문 안 닫았어!**(창가를 지나면 떠밀린다) /
    🏠 **윗집에서 또 쿵쿵거려!**(몸도 물건도 들썩인다) /
    🌑 **정전이야!**(물건이 실루엣만 보인다)
  - 오토캠핑 데크 — 🦝 **너구리가 물어간다!**(던져서 맞혀야 되찾는다) /
    🌧️ **비 온다, 발밑 조심!**(바닥이 미끄러워 방향 전환이 밀린다)

### 종료 조건
라운드마다 12초 난투 → AI 심사위원 채점(0~100점) + 한 줄 평 →
3라운드 합산 최고 득점자가 우승. 우승자에게는 AI의 축하 총평이 주어진다.

## 실행 방법

**설치가 필요 없다.** 브라우저만 있으면 된다 — 다운로드, 계정 가입, 플러그인 모두 불필요.
접속하면 바로 로비가 뜨고, 참가 키를 누르면 시작한다.

| 방식 | 방법 |
|---|---|
| **웹 플레이 (권장)** | 아래 플레이 링크 접속 → 즉시 실행 |
| 로컬 실행 | `npm install` → `npm run dev` → `localhost:5173` (Node.js 18+) |

권장 환경: Chrome / Edge 최신 버전, 데스크톱·노트북 (WebGL2 지원 필요).
2인 플레이는 키보드 한 대를 좌우로 나눠 쓰므로 별도 장비가 필요 없다.
